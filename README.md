# MISE QA Test Assignment

В репозитории представлены результаты ручного тестирования формы бронирования, API-тестирование в Postman и дополнительные UI-автотесты на Playwright.

## Результаты тестирования

В папке `test report` находится отчёт, содержащий:

- чек-лист;
- тест-кейсы и результаты их выполнения;
- баг-репорты;
- итоги тестирования.

Также отчёт доступен по [ссылке](https://docs.google.com/document/d/1bWxqjvBXWL_dNnl0c3X3EU7MfeqTEN_wC8gR2pkGzK0/edit?usp=sharing)

В папке `postman collection` находится экспортированная Postman-коллекция с позитивным и негативными сценариями проверки API.

Добавлены тесты для существующих сценариев, а также два дополнительных сценария - проверка валидации даты в следующем году, а также проверка валидации поля количества гостей (13).

## UI-автотесты

В качестве дополнительной части задания реализовано 5 UI-тестов на TypeScript Playwright:

- успешное бронирование;
- `TC-02` — валидация обязательных полей;
- `TC-11` — валидация кода страны номера телефона;
- `TC-16` — проверка временных слотов с 12:00 до 22:00;
- `TC-24` — очистка формы при повторном бронировании.

Тесты `TC-11`, `TC-16` и `TC-24` ожидаемо завершаются с ошибкой, поскольку воспроизводят обнаруженные дефекты приложения.

## Запуск автотестов

Установка зависимостей:

```bash
npm install
npx playwright install
```

Запуск тестов:

```bash
npm test
```
